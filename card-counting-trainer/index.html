How the Hi-Lo system works

Blackjack is one of the few casino games where the odds change as cards come out of the shoe. A deck rich in high cards (10s and Aces) favors the player: you get more blackjacks, double-downs win more often, and the dealer busts more. Hi-Lo tracks that balance with a single number.

Step 1 — Keep a running count

  1. Start at 0 when the dealer shuffles.
  2. For every card you see, add its value: +1, 0, or −1.
  3. Keep going across hands until the next shuffle.

Example: 5, K, 3, 8, 2, A → +1 −1 +1 0 +1 −1 = +1

Tip: count cards in pairs. A low and a high card cancel out (e.g. 4 + Q = 0), so you can skip past them.

Step 2 — Convert to a true count

A +6 running count means a lot with one deck left, and very little with six. Divide by the decks still in the shoe:

True Count = Running Count ÷ Decks Remaining

Example: running count +8 with 4 decks left → true count +2. Estimate decks left by eyeballing the discard tray.

Every +1 of true count shifts the edge about 0.5% toward the player. A full deck always counts to exactly 0, which is a handy self-check.

Practice path

  1. Card Values — make the +1/0/−1 instant and automatic.
  2. Running Count — keep a count while cards are dealt at speed.
  3. True Count — practice the division until it's quick.

This is a learning tool. Card counting is legal, but casinos may ask counters to leave or stop playing blackjack.
